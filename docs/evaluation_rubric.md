# Assessment rubric — Surface‑EMG lab practicals (emgteach)

> A rubric to assess the student deliverables of the
> [lab practical guide](lab_practicals.md). Each criterion is scored **0–10** and
> weighted; the final mark is the **weighted average**. The performance‑level
> descriptors below help grade consistently. Adjust weights to your course.

## Criteria and weights

| # | Criterion | Weight |
|---|---|---|
| 1 | Setup and recording quality | 20 % |
| 2 | Data collection and event markers | 15 % |
| 3 | Use of the application and analysis | 20 % |
| 4 | Physiological interpretation | 30 % |
| 5 | Report and presentation | 15 % |

**Final mark = Σ (criterion score × weight).**

## Performance‑level descriptors

Levels: **Insufficient (0–4)** · **Sufficient (5–6)** · **Good (7–8)** ·
**Excellent (9–10)**.

### 1. Setup and recording quality (20 %)

- **Insufficient.** Poor electrode placement; recordings dominated by artefacts or
  saturation; signal unusable.
- **Sufficient.** Acceptable placement; usable recording with some artefacts.
- **Good.** Correct placement and reference; clean recording, low noise.
- **Excellent.** Optimal placement; consistently clean recordings across channels;
  artefacts identified and corrected.

### 2. Data collection and event markers (15 %)

- **Insufficient.** Missing data; events not marked; tables incomplete.
- **Sufficient.** Most data collected; some markers/tables incomplete.
- **Good.** Complete data; events correctly marked (manual/automatic).
- **Excellent.** Complete, well‑organised data; markers precise and meaningful;
  appropriate use of the PDF report as evidence.

### 3. Use of the application and analysis (20 %)

- **Insufficient.** Does not use the right panels/metrics; misreads the tools.
- **Sufficient.** Uses the basic panels/metrics with guidance.
- **Good.** Selects the appropriate panels (RMS, PSD, MDF, APDF) and reads the
  metrics correctly; uses the navigator/time range adequately.
- **Excellent.** Fluent, autonomous use; chooses the right analysis for each
  question; uses normalisation (% MVC) and load analysis appropriately.

### 4. Physiological interpretation (30 %)

- **Insufficient.** Incorrect or absent reasoning; confuses amplitude/frequency.
- **Sufficient.** Basic, mostly correct interpretation; limited depth.
- **Good.** Correct interpretation: relates amplitude to activation, the spectral
  shift to fatigue, and % MVC / Jonsson levels to load.
- **Excellent.** Accurate, well‑argued interpretation; connects observations to the
  underlying physiology (recruitment, conduction velocity, ergonomic risk) and
  draws sound conclusions.

### 5. Report and presentation (15 %)

- **Insufficient.** Disorganised; missing figures; unclear; no conclusions.
- **Sufficient.** Acceptable structure; basic figures; brief conclusions.
- **Good.** Clear, well‑structured report; relevant figures/tables; coherent
  conclusions.
- **Excellent.** Professional report; well‑chosen figures (or PDF reports); precise
  language; insightful conclusions.

> informative: it reveals whether the student understands *what the numbers mean*,
> not just how to produce them.
